                               d(ykn , y) < 2r    for all n ≥ N1 .

h2 ◦ h1 : A → C is also bijective, and so A ∼ C.

Problem 2. Given two points (x1 , y1 ) and (x2 , y2 ) in R2 = {(x, y) : x, y ∈ R}, we write

               (x1 , y1 ) < (x2 , y2 )   ⇐⇒       x1 < x2      or (x1 = x2 and y1 < y2 ).

 (a) Prove that < is an order relation on R2 .
 (b) Prove that (R2 , <) does not satisfy the least upper bound property.

Solution: (a) By definition of an order relation, there are two properties to check.
   Trichotomy: Fix (x, y), (x0 , y 0 ) ∈ R2 . We will prove that in every possible case, exactly
one of the statements ‘<’, ‘=’, or ‘>’ is true.

    • Case: x < x0 . Then (x, y) < (x0 , y 0 ).
    • Case: x > x0 . Then (x, y) > (x0 , y 0 ).
    • Case: x = x0 .
         – If y < y 0 : Then (x, y) < (x0 , y 0 ).
         – If y > y 0 : Then (x, y) > (x0 , y 0 ).
         – If y = y 0 : Then (x, y) = (x0 , y 0 ).

    Transitivity: Suppose (x1 , y1 ) < (x2 , y2 ) and (x2 , y2 ) < (x3 , y3 ). By definition of ‘<’, there
are four possible cases.

    • Case: x1 < x2 and x2 < x3 . Then x1 < x3 , and so (x1 , y1 ) < (x3 , y3 ).
    • Case: x1 < x2 , x2 = x3 , and y2 < y3 . Then x1 < x3 , and so (x1 , y1 ) < (x3 , y3 ).
    • Case: x1 = x2 , y1 < y2 , and x2 < x3 . Then x1 < x3 , and so (x1 , y1 ) < (x3 , y3 ).
    • Case: x1 = x2 , y1 < y2 , x2 = x3 , and y2 < y3 . Then x1 = x3 and y1 < y3 , and so
      (x1 , y1 ) < (x3 , y3 ).

So, in all cases, we have (x1 , y1 ) < (x3 , y3 ).

    (b) Suppose towards a contradiction that (R2 , <) satisfies the least upper bound property.
    Set Y = {(0, y) : y ∈ R}. Then:

    • Y is nonempty: since (0, 0) ∈ Y .
    • Y is bounded above: by (1, 0).

So, by the least upper bound property, there exists a least upper bound (a, b) ∈ R2 for Y .
    Claim: a > 0. If a < 0, then (0, 0) would be a point in Y with (0, 0) > (a, b), which would
contradict that (a, b) is an upper bound for Y . If a = 0, then (0, b + 1) would be a point in
Y with (0, b + 1) > (a, b), which would contradict that (a, b) is an upper bound for Y . The
only remaining possibility is a > 0.
    As a > 0, then ( a2 , b) is also an upper bound for Y :

                               0 < a2    =⇒          (0, y) < ( a2 , b) ∀y ∈ R.

On the other hand, we have a2 < a, and so ( a2 , b) < (a, b). This contradicts that (a, b) was
the least upper bound.

                               S = {a + b : a ∈ A and b ∈ B}.

Solution: As A, B ⊆ R are nonempty and bounded, we know that sup A and sup B exist.
We will prove that sup A + sup B satisfies the definition of ‘least upper bound’ for the set S.
   Claim: sup A + sup B is an upper bound for S. As sup A is an upper bound for A, we
know
                                a ≤ sup A for all a ∈ A.
Similarly, sup B is an upper bound for B, and so

                                  b ≤ sup B    for all b ∈ B.

Adding these two inequalities, we conclude that

                      a + b ≤ sup A + sup B    for all a ∈ A and b ∈ B.

Therefore sup A + sup B is an upper bound for S.
   Claim: If L is an upper bound for S, then L ≥ sup A + sup B. Suppose towards a
contradiction that L is an upper bound for S but L < sup A + sup B. Set

                                = 21 (sup A + sup B − L) > 0.

                                       b0 > sup B − .
