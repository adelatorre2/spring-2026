                      How to Use This Workbook
This workbook is for active proof practice. For each problem, work through the diagnosis,
recipe card, self-explanation, skeleton, and full proof attempt before reading the reference
solution.
Pass 1      Diagnose the topic, task, relevant definitions, and likely proof method.

Pass 2      Convert the problem into hypotheses, conclusion, tools, and a proof plan.

Pass 3      Answer targeted questions that expose the proof’s logic.

Pass 4      Reconstruct the proof from a skeleton without reading the full solution.

Pass 5      Write a complete proof from scratch in the blank writing space.
Only after Pass 5 should you compare your work to the official or reference solution.

(a) Fix x ∈ U ∩A. We show x ∈ U ∩ A, i.e., for any r > 0, Br (x)∩U ∩A is nonempty.
    Fix r > 0. Since x ∈ U and U is open, there exists s > 0 such that Bs (x) ⊆ U .
    Set re = min{r, s}. Since x ∈ A, the set Bre(x) ∩ A is nonempty, so choose
    y ∈ Bre(x) ∩ A.
    Then y ∈ A. Also y ∈ Br (x), since d(y, x) < re ≤ r. Finally y ∈ U , since
    d(y, x) < re ≤ s, so y ∈ Bs (x) ⊆ U . Hence y ∈ Br (x) ∩ U ∩ A, as desired.
(b) Recall that B ⊆ C implies B ⊆ C. Applying this to part (a),

                                   U ∩ A ⊆ U ∩ A.

    On the other hand, A ⊆ A, so U ∩ A ⊆ U ∩ A. Therefore

                                   U ∩ A ⊆ U ∩ A.

    Together,
                                   U ∩ A = U ∩ A.
(c) For any set B, B ⊆ B. If U ∩ A = ∅, then U ∩ A = ∅. By part (b),

                                     U ∩ A = ∅.

    Therefore U ∩ A = ∅.

Official Solution (Professor)

⇒ Suppose xn → x in (X, d) as n → ∞. Fix an open set U ⊆ X such that x ∈ U .
Since U is open, there exists r > 0 such that Br (x) ⊆ U . By definition of convergence,
there exists N such that d(xn , x) < r for all n ≥ N . Therefore xn ∈ Br (x) ⊆ U for all
n ≥ N.
⇐ Suppose that for every open set U containing x, we have xn ∈ U for all but
finitely many n ∈ N. Fix r > 0. Apply the assumption to the open set Br (x). Then
xn ∈ Br (x) for all but finitely many n ∈ N. Let N be larger than the largest index for
which xn ∈/ Br (x). Then for every n ≥ N , xn ∈ Br (x), and hence d(xn , x) < r. Since
r > 0 was arbitrary, {xn }n≥1 converges to x in (X, d).

Official Solution (Professor)

Fix y ∈ X. By the triangle inequality,

            d(xn , y) ≤ d(xn , x) + d(x, y)    =⇒ d(xn , y) − d(x, y) ≤ d(xn , x),
             d(x, y) ≤ d(x, xn ) + d(xn , y)   =⇒ d(x, y) − d(xn , y) ≤ d(xn , x).

Together,
                               |d(xn , y) − d(x, y)| ≤ d(xn , x).
Since {xn }n≥1 converges to x in (X, d), the right-hand side converges to 0. Therefore,
by the squeeze theorem,
                               |d(xn , y) − d(x, y)| → 0,
and thus d(xn , y) converges to d(x, y).
