                      How to Use This Workbook
This workbook is for active proof practice. For each problem, work through the diagnosis,
recipe card, self-explanation, skeleton, and full proof attempt before reading the reference
solution.
Pass 1      Diagnose the topic, task, relevant definitions, and likely proof method.

Pass 2      Convert the problem into hypotheses, conclusion, tools, and a proof plan.

Pass 3      Answer targeted questions that expose the proof’s logic.

Pass 4      Reconstruct the proof from a skeleton without reading the full solution.

Pass 5      Write a complete proof from scratch in the blank writing space.
Only after Pass 5 should you compare your work to the official or reference solution.

Fix N ≥ 1. For n ≥ N we have

                 an ≤ sup{an : n ≥ N },        bn ≤ sup{bn : n ≥ N },

and so
                   an + bn ≤ sup{an : n ≥ N } + sup{bn : n ≥ N }.
In other words, sup{an : n ≥ N } + sup{bn : n ≥ N } is an upper bound for the set
{an + bn : n ≥ N }. Therefore

            sup{an + bn : n ≥ N } ≤ sup{an : n ≥ N } + sup{bn : n ≥ N }.

Altogether, we have shown that for any N ≥ 1 we have

            sup{an + bn : n ≥ N } ≤ sup{an : n ≥ N } + sup{bn : n ≥ N }.

As {an } is a bounded sequence, we know from lecture that the sequence vN = sup{an :
n ≥ N } converges to v = lim sup an ∈ R. Similarly, as {bn } is bounded, the sequence
sup{bn : n ≥ N } converges to lim sup bn as N → ∞. By the inequality above, we see
that the sequence sup{an + bn : n ≥ N } is also bounded above. Therefore lim sup(an +
bn ) is a finite number, and sup{an + bn : n ≥ N } converges to lim sup(an + bn ) as
N → ∞.
By the limit laws, the sequence

            sup{an + bn : n ≥ N } − sup{an : n ≥ N } − sup{bn : n ≥ N }

converges as N → ∞. We also know that it is ≤ 0 for all N ≥ 1. Therefore, by
HW4#3, the limit is also ≤ 0:

                    lim sup(an + bn ) − lim sup an − lim sup bn ≤ 0

and hence
                     lim sup(an + bn ) ≤ lim sup an + lim sup bn .
                       n→∞                 n→∞          n→∞
