Student-Derived Solution (No official solution available)

For n ∈ N, let P (n) denote the statement

                          3 + 11 + · · · + (8n − 5) = 4n2 − n.

We argue by induction.
Base case. For n = 1, the left-hand side is 3, while the right-hand side is

                                    4 · 12 − 1 = 3.

Hence P (1) holds.
Inductive step. Assume P (n) holds for some n ∈ N, i.e.

                          3 + 11 + · · · + (8n − 5) = 4n2 − n.

We must show that P (n + 1) holds. The next term in the sum is

                                8(n + 1) − 5 = 8n + 3.

Adding this term to both sides of the inductive hypothesis gives

              3 + 11 + · · · + (8n − 5) + (8n + 3) = (4n2 − n) + (8n + 3).

The right-hand side simplifies to

                                     4n2 + 7n + 3.

On the other hand,

            4(n + 1)2 − (n + 1) = 4(n2 + 2n + 1) − n − 1 = 4n2 + 7n + 3.

Therefore
                 3 + 11 + · · · + (8(n + 1) − 5) = 4(n + 1)2 − (n + 1),
so P (n + 1) holds. By the principle of mathematical induction, P (n) is true for all
n ∈ N.

Student-Derived Solution (No official solution available)

(a) Suppose first that f is injective. Let X ⊆ A. If x ∈ X, then f (x) ∈ f (X), so
x ∈ f −1 (f (X)). Hence X ⊆ f −1 (f (X)).
Conversely, let a ∈ f −1 (f (X)). Then f (a) ∈ f (X), so there exists x ∈ X such
that f (a) = f (x). Since f is injective, a = x ∈ X. Thus f −1 (f (X)) ⊆ X, so
f −1 (f (X)) = X.
Now suppose f −1 (f (X)) = X for all X ⊆ A. Let a1 , a2 ∈ A and assume f (a1 ) = f (a2 ).
Set X = {a1 }. Then f (a2 ) = f (a1 ) ∈ f (X), so

                             a2 ∈ f −1 (f (X)) = X = {a1 }.

Hence a2 = a1 , and f is injective.
(b) Suppose first that f is surjective. Let Y ⊆ B. For any function, f (f −1 (Y )) ⊆ Y :
if b ∈ f (f −1 (Y )), then b = f (a) for some a ∈ f −1 (Y ), hence f (a) ∈ Y , so b ∈ Y .
For the reverse inclusion, let y ∈ Y . Since f is surjective, there exists a ∈ A such that
f (a) = y. Then a ∈ f −1 (Y ), so y = f (a) ∈ f (f −1 (Y )). Thus Y ⊆ f (f −1 (Y )), and
f (f −1 (Y )) = Y .
Conversely, suppose f (f −1 (Y )) = Y for all Y ⊆ B. Fix b ∈ B. Let Y = {b}. Then

                                   f (f −1 ({b})) = {b}.

Thus f −1 ({b}) ̸= ∅, so there exists a ∈ A with f (a) = b. Since b ∈ B was arbitrary,
f is surjective.

⇒ Assume that f is surjective. Let C be any set, and let g, h : B → C satisfy
g ◦ f = h ◦ f . We show g = h. Fix b ∈ B. Since f is surjective, there exists a ∈ A
such that f (a) = b. Then

             g(b) = g(f (a)) = (g ◦ f )(a) = (h ◦ f )(a) = h(f (a)) = h(b).

Since b ∈ B was arbitrary, g = h.
⇐ Assume the cancellation property in (b). Suppose, for contradiction, that f is not
surjective. Then there exists b0 ∈ B \ f (A). Let C = {0, 1}, and define g, h : B → C
by
                                g(b) = 0 for all b ∈ B,
and                                      
                                         1,   b = b0 ,
                                 h(b) = 
                                            0, b ̸= b0 .
Then g ̸= h, since g(b0 ) = 0 but h(b0 ) = 1. However, for every a ∈ A, we have
f (a) ̸= b0 , so
                 (g ◦ f )(a) = g(f (a)) = 0 = h(f (a)) = (h ◦ f )(a).
Thus g ◦ f = h ◦ f , and by the assumed property this forces g = h, a contradiction.
Therefore f is surjective.
